# homebrew-river

Homebrew tap for [River](https://github.com/abgregs/river): dictation that follows you wherever you go.

```bash
brew install --cask abgregs/river/river
```

The cask in `Casks/` is generated by River's release workflow from [`packaging/homebrew/river.rb`](https://github.com/abgregs/river/blob/main/packaging/homebrew/river.rb). Changes to the cask go through that file, not this repo.
